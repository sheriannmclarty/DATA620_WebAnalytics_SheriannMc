# DATA620_WebAnalytics_SheriannMc
Network Analysis + Text Mining using Python (NetworkX, NLTK)

This repository contains my coursework for **DATA 620 – Web Analytics** in the CUNY School of Professional Studies M.S. in Data Science program.

## Course focus
The course introduces methods for analyzing online behavior using two complementary approaches:

**Network analysis**
- Graph construction (nodes/edges) and visualization
- Network measures including centrality, cohesion, clustering, affiliations, and 2-mode networks
- Interpreting network structure and roles in applied contexts

**Text mining / NLP**
- Text preprocessing and representation
- Word association, topic mining, and sentiment analysis
- Introductory text-based prediction

**Web analytics context**
- Website traffic concepts such as clickstreams, referrals, keywords, page views, and drop-offs
- Overview of search algorithms and search engine optimization (SEO)

The course also addresses relevant social science concepts (e.g., homophily, social capital, trust, motivations) and ethical/privacy considerations in the use of online data.
